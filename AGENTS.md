# Archived project

Read `ARCHIVE-RESTORE.md` before restoring or running this project. Large editable assets and the existing builds are GitHub release assets; the repository contains the browsable source snapshot.

The original Windows installation and its machine-specific storage policy were retired at the owner's request. Do not invoke cleanup against the old C: or D: paths, recreate deleted snapshot chains, or assume historical deployment pointers identify a running service.

When development resumes, use bounded generated-output directories and preserve editable source. Do not copy dependencies, Git internals, or previous snapshots recursively into new artifacts. Establish retention appropriate to the new machine before generating bulk output.
