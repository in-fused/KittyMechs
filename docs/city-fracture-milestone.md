# Original component fracture — private implementation

2026-10-05. This iteration replaces the Rainline city's generic small box chips with eight closed, source-sized fragments per accepted structural break. Pieces reconstruct the original CityBlock cuboid at birth, retain its center, yaw, exterior material and meter-scale UVs, then tumble in the winning impact direction. The shared damage masks, cell retirement, support dependencies and guest geometry remain authoritative. No runtime cutting or new project dependency is introduced.

This is a cosmetic fracture implementation over the existing permanent openings. Dynamic rubble collision, occupants being hit by rubble, damaged-face grip wear, arbitrary contact damage, progressive cracks, unsupported-sector fall effects and whole-building collapse remain open. Attached glazing/trim are retired with their existing owner; the fractured shell represents the closed cuboid component, not every decorative submesh. Other maps and immutable building classes remain outstanding. Reusing the same eight-piece template is also an art limitation.
