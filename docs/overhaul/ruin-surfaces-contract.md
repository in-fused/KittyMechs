# Settled ruin contact surfaces

`shared/overhaulRuinSurfaces.ts` compiles revision-bound `BuildingFace` descriptors from the owner's actual six oriented cuboid patches. Only vertical walls and horizontal roofs, within 1e-5 native rotation roundoff, are representable by the existing gravity-aligned articulated climbing owner. Arbitrary yaw remains exact. Tilted walls/roofs are rejected rather than flattened. Coplanar strips from a physical settled stack may share one wall envelope, but each source retains its own collider key; holes, tiny gaps, opposite faces and occluding cells still fail native five-point paw or roof proofs. A descriptor never adds collision.

Interfaces:

- `new OverhaulRuinSurfaces(source)` accepts `OverhaulRuinsOwner` or `OverhaulRuinCollisionOwner` (both expose `patches(true)` and `collider(block)`).
- `sync()` refreshes settled fixed sources and returns retired face IDs. Membership, source birth, revision and handle changes invalidate bindings. `read()` exposes immutable-current face descriptors; `nearby(position,range,limit=16)` sorts exact face distances.
- `collider(key)` resolves a source/birth/revision key to its current enabled fixed collider. `live(faceOrId)` requires its complete current wall and roof ownership.
- `overhaulRuinSnapshotFaces(district,validatedRuins)` derives the same descriptors for network admission without a native world. Call only after ruin state and broken source masks are validated.
- `registerOverhaulRuinSurfaces(world,owner)` returns generation-safe cleanup; `overhaulRuinWorldSurfaces(world)` reads the current authority/guest owner for `Actors` contact lookup.
