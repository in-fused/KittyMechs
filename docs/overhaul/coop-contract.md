# Integrated district co-op lifecycle

The experimental co-op authority owns `OverhaulCoop`; established modes omit snapshot `coop` and retain their existing death behavior. Protocol input is unchanged. Actor `downed` and snapshot `coop` are optional authoritative fields.

- Accepted lethal human damage retires combat, jump, grip and collision, then calls `down(actor,time)`. No timed respawn is allowed for `downed`; the existing corpse motion settles against actual terrain. Blocked initial placement has zero armor but no downed receipt and stays a bounded placement retry.
- A living grounded pilot holds E within 4.5 m of a settled downed teammate for three seconds with a clear rescue ray. Rescue takes priority over supplies and relay capture. Movement above 1.5 m/s, damage within 0.3 seconds, climbing, paired action, strike, release, lost range, blocked ray or stale input resets progress. One pilot owns each channel; extra pilots cannot accelerate it.
- Simulation's `restore` hook checks the entire quadruped hull at the corpse position and restores native ownership in-place. The helper grants 40% armor only after that hook succeeds. A blocked hull remains downed; it is never rescued by teleporting to the checkpoint.
- All currently connected humans with downed receipts cause a failed attempt. Combat and mission progress stop. Time and validated inputs continue. A new E press after the one-second cooldown retries; held or expired packets cannot counterfeit a release. A join during failure becomes downed and participates in that retry; disconnect uses the current connected roster.
- Retry preserves completed objectives, latest checkpoint, salvage, structural damage and persistent ruins. Incomplete objective progress resets. Simulation clears transient combat/projectiles/fields and uses its existing full-hull checkpoint spawn finder for every human. A blocked checkpoint placement stays pending instead of spawning inside geometry.
- Defeated placed Rainline co-op enemies remain defeated for the simulation/session, including checkpoint retries. Accepted lethal damage records a bounded authority-owned NPC ID receipt; timed and direct respawn paths respect it. Corpses still settle and retain disabled collision. A fresh room/simulation initializes a fresh roster. Existing one-time kill/salvage awards, optional guardian checks, objective dependencies, supplies and other modes/maps retain their behavior.

Integration calls `advance` once after combat in each active tick and once in each frozen failed tick. Inputs passed to it must use the existing authoritative 0.3-second freshness timeout. Failed ticks still increment simulation time/tick. Snapshot publication copies `coop` and each nested `downed` object. `phase` remains active/extracted; failure is represented by `coop.status` so existing result handling stays compatible. Input reconciliation permits E while failed; authority suppresses other downed actions. HUD exposes rescue progress and checkpoint retry instructions.

Ten focused helper tests exercise timed transitions, interrupted/blocked rescue, single-channel ownership, failed/late-join roster behavior, explicit retry edges and checkpoint progress preservation. Six integrated Rapier cases in `tests/overhaul-coop-native.test.ts` additionally exercise actual damage acceptance, native downed-collider retirement, seven seconds without automatic rebuild, in-place enabled-hull restoration and subsequent movement, solid rescue-ray blocking, checkpoint retry with structure damage retained, failed late-join collision retirement and Ember compatibility. Snapshot admission accepts the native states and detaches downed metadata. These tests do not establish two-client rendering, browser input delivery or ordinary mission completion; those require browser evidence from the primary agent. There is no bleedout timer, carried-body rescue, or mission-wide restoration of destroyed geometry in this bounded district implementation.

The later `mission-004` ordinary-play failure exposed the old shared 22-second enemy respawn: a defeated WORKS SCOUT returned behind pilots still clearing the next encounter. Eight native regression cases in `tests/overhaul-coop-defeat.test.ts` now prove authored street scout/roof guardian defeats persist past that deadline, duplicate damage grants no second award, late-join snapshots preserve cleared NPCs, checkpoint retry and a further 25 seconds retain defeat, and a new room restores the roster. PvP/PvPvE/training and Ember/Frostline co-op retain their normal timers. The focused defeat/current native co-op run passes 15 cases across two files. This is lifecycle qualification, not a new ordinary mission-victory claim.
