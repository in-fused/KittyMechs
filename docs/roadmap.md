Every iteration requires simulation/asset/browser checks and an independent critic's separate approvals for mechs, maps/world, combat/AI and integration. Denied work returns for repair. `release:check` verifies the receipt against current gameplay/assets/tests/tools/build configuration and blocks stale approvals; compiled browser playtesting remains separately mandatory. Record limitations honestly and keep generated concept art distinct from gameplay.

The legacy project remains preserved until its unique source/design material is retained and the browser replacement is qualified. Conditional deletion is a later migration decision.
