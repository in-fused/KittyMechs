Private iteration, 2026-10-06. Current source and the local production build contain the correction described below. The independent critic approves only the yaw-rate correction and bounded local integration. The frozen public friend build is unchanged, and all four formal release areas remain pending.

## Problem and behavior

The earlier [displayed motion correction](displayed-motion-rate-milestone.md) fixed gait and turn-selection rates. The separate torso/tail reaction still divided actual displayed heading change by cosmetic integration time capped at 50 ms. On an unsaturated 100 ms or 300 ms display interval, that could exaggerate this reaction by about two or six times. Actual captured intervals, rather than declared stall durations, determine the measured ratio.

`displayedYawRate` now measures signed shortest-angle travel over the full elapsed interval. It preserves the 1 ms denominator floor and the signed 3 rad/s cap; nonfinite angles/intervals and nonpositive intervals return zero. `Actors.tsx` passes the saved elapsed interval to this consumer while retaining the existing 50 ms cosmetic integration cap, lean limits/filter, stance factors, strike layering and tail tracking factors. Finite intervals through 50 ms retain the former rate and lean target. A filter's later state can differ correctly after a preceding long frame.

The render timeline still advances with its existing capped interval. The numerator is the heading segment actually returned by that timeline; it is not an assumed native velocity multiplied by full elapsed time. Native authority, root motion, physics, timeline behavior, IK, chassis profiles, authored clips, models, materials, grip profiles and dependencies remain unchanged by this correction. No spring or alternative controller was added.

Read-only contact diagnostics record elapsed/capped intervals and reaction inputs/results. A warmed `contactSnapshot` detaches the completed frame at invocation before yielding, preserving its asynchronous Promise contract. Previously the dynamic-import await could let a subsequent catch-up frame replace the completed long frame before copying. This diagnostic correction provides observation, not a second animation or movement authority.
