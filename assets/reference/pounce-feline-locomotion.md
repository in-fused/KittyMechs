# Pounce feline locomotion revision

The new motion uses the existing Pounce model, rigid weights and unchanged rest skeleton. It replaces the upright walking action with a low four-limb bound: forelimb contacts lead, hind limbs gather and drive, the pelvis and spine compress, and the tail balances rearward. The chest counter-rotates so the existing face and cockpit remain readable. Bastion retains its current gait.

The authored cycle is 0.5 seconds. Forelimb stance is 0.10 seconds/76 centimetres; hindlimb stance is 0.08 seconds/60.8 centimetres at 760 cm/s. Runtime scales playback by actual speed/760 and turns the pose toward movement except while firing or shielding, without rotating the gameplay capsule or changing the camera, weapon origin, movement speed or collision. An authored tucked/reaching air pose blends in during falling, then blends back into grounded motion on landing. There is no runtime paw IK or new authored combat/downed animation; slow starts and abrupt turns still use blends.

`Art/Validation/Locomotion/feline-001` is retained as a rejected first pose: its chest faced too far downward and its tail was too upright. `feline-002` preserves the source blend, three single-action FBXs and an actual twelve-frame Blender preview (`gallop.gif`, 0.5-second loop). Both Blender jobs exited successfully. The third revision, `feline-003`, extends forelimb reach/push and lifts the folded recovery after critic feedback. It completed actual rendering and remains subject to independent review and Unreal playback; authoring success is not gameplay acceptance.

`Tools/Unreal/import_pounce_feline.py` imports only the reviewed revision's animations into `/Game/Mechs/Pounce/Feline`, using the canonical shared skeleton. It refuses an occupied destination. The original model, skeleton and Idle/Walk packages remain intact. Runtime adopts all three new clips together only after compatibility checks, with the original clips as fallback. `-KMPrimitiveArt` continues to provide the separate primitive diagnostic fallback.

New observations: character `HasFelineLocomotion()` and `GetFelineAirClip()`; animation `IsFelineLocomotion()` and `GetAirWeight()`; receipts include `feline_locomotion`, `art_air_clip`, and `feline_air_weight`. Existing `GetWalkPlayRate()` now reports a variable rate for Pounce; a fixed-rate-one assertion would be incorrect for the new gait. Capsule and component transform observations remain unchanged.
