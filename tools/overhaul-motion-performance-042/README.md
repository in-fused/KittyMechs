## Concrete causes and changes

1. Owner005 selected gait based on displayed displacement, then zeroed all its weights for any full-body Pulse/Missile/Hit window. FelinePulse lasts .33333334s while native firing can refresh pulseAt every .16s; sustained firing therefore replaces walking with stationary-foot recoil continuously. The repair keeps gait while displayed speed is above the existing .08m/s movement threshold. Stationary authored reactions remain, as do critical transform/air/pair/strike branches and prior landing selection behavior. Ordinary muzzle/projectile presentation remains. Moving whole-body recoil is intentionally limited; no new additive/upper-body overlay, IK, contact certificate or authored asset is invented.

2. SkeletonUtils.clone makes a separate Skeleton for each SkinnedMesh material primitive. The prototype wrappers retained those duplicates, whereas the normal actor path already shares palettes. Installed Three WebGLObjects caches `skeleton.update()` by Skeleton identity per frame; every redundant palette repeats bone matrix computation and can upload another bone texture. `shareSkinPalettes042` runs once on each actor clone and shares only exact ordered Bone object owners and exact finite inverse-matrix elements. Different inverses, owners or ordering remain separate. Mesh bind matrices, geometry, skin weights and mesh/bone transforms remain intact. Unused cloned palettes are disposed; canonical owned palettes retain existing teardown. The helper is attached to public034, public008, internal007 and005 wrappers, without changing the actor roster, other prototypes or source GLBs. Actor clones cannot share bone owners across actors.

3. Weighted envelope sampling computes one final aggregate AABB, then previously returned its identical eight corners repeated once per material mesh. Camera fitting projected all those duplicates at every fit probe. Corner count is now eight; the complete weighted geometry, positive sum ranges, ownership/matrix checks, arithmetic padding and aggregate bounds are unchanged. This eliminates redundant projection work, not geometry or validation. Per-mesh weighted validation still has a cost; this packet does not waive or rewrite it.

These are causal code mechanisms and bounded work reductions. The fraction of the user's actual lag explained by them remains a root measurement, including renderer/GPU/server/browser load and the camera issue.
